# 整车 FPGA 引脚、电平与连接器分配

本表记录板卡连接器、IO 电平和外设分配。共同工程使用 CH 导航串口、P11-40 / A16 控制遥测及 P11-7/8 BMI088 I2C；P11-39 外部速度输入关闭。SFP1 为独立扩展，连接 P6 / U11、Q0 Lane2。

第 3 节列出导航独立台架的约束，第 4 节列出控制外设分配；构建时以所选共同顶层的 CST 为准。协议与单位见 [ICD](icd.md)，物理实现核对见[PNR63 报告](../4_design/g2_PNR63_review_20261028.md)。

2026-10-30补充超声波、SG90和J4 RGB LCD分配（第4.1、7.1节）。这些新增端口依据控制组`715378a`及厂家原理图核对，尚未加入PNR63；接线表更新不表示当前SRAM镜像已支持它们。

| 版本 | 改动 |
|---|---|
| v0.1 | 初稿：IMU 按 TTL 串口放在第 1 / 2 针 |
| v0.2（历史建议，已被取代） | 曾拟将第 1–7 针给 BMI088 SPI、第 8 针给急停、第 9/10 针给主机 UART；未据此完成整车实现 |
| v0.3 | 按控制源码核对：第 1–4 针舵机、第 5/6 针 OLED、第 7/8 针 BMI088 I2C、第 15–24 针 AB 编码器与电机驱动、第 39/40 针控制 UART；撤销冲突旧分配，物理急停引脚待定 |
| v0.4（2026-10-30） | P11-36 SG90 PWM、37 Echo、38 Trig；列全J4 LCD的21个信号针号/FPGA球脚/Bank，核对CPU/SSPI复用；新增功能待联合构建 |

## 1. 依据

- 厂家《ACX750-GW5A138开发板管脚信息表.xlsx》：信号名 → FPGA 管脚；
- 底板原理图 `ACX750-GW5A138-CB-250928.pdf`：第 10 页 P11 针号 ↔ 网络名，第 6 页 VCCIO2 选择电路；
- 当前比特流布线报告 `gowin/syn/build_board/impl/pnr/nav_board_top.rpt.txt` 第 7 节：每个引脚的 Bank、方向、上下拉。
- 控制外设约束：`control/fpga/src/main.cst`、`main.v` 和控制 README 接线表。
- 新增外设来源：[控制组715378a的main.cst](https://github.com/Chenyudog/fpga/blob/715378aa3228d0cdcc382882ab53edc7400ef89c/fpga/src/main.cst)；本地`control/`仍是旧来源，不得误认为已含新增约束。LCD的J4物理针号由底板原理图第9页`09_LCD&CMOS`核对，P11由第10页核对。

P11（2×20 排针）的针号与 GPIO0 编号：1–10 针 = GPIO0_0..9，11 针 = 5 V，12 针 = GND，13–28 针 = GPIO0_10..25，
29 针 = 3.3 V，30 针 = GND，31–40 针 = GPIO0_26..35。奇数针与相邻偶数针是一对差分线（P / N），单端使用没有问题。
接线前仍要对照底板丝印确认第 1 针的位置。

## 2. 电平：接任何外设之前先确认

- P11 的 36 个 IO 全部在 FPGA **Bank 2**，由 VCCIO2 供电。VCCIO2 由底板跳线 **P9**（2×4）选择：
  7–8 短接 = 3.3 V（直接接 VCC3P3）；1–2 = 2.5 V，3–4 = 1.8 V，5–6 = 1.5 V（经 U15 SPX3819 可调稳压）。
- 本工程的约束全部按 **LVCMOS33** 写（布线报告：C18 / C19 在 Bank 2、3.3 V），所以 **P9 必须短接 7–8**。
  第一次接外设前，用万用表量测试点 **TP8（VCCIO2）对地 = 3.3 V**。复位键 S0（D21）和拨码开关 SW6 / SW7 也在 Bank 2。
- 只接 3.3 V 逻辑。5 V TTL 输出要加电平转换（74LVC245、TXS0108 或电阻分压），RS232 要加 MAX3232，RS485 / CAN 要加收发器芯片。
- 每脚驱动能力按约束 `DRIVE=8`（8 mA）：只驱动逻辑输入，不直接带继电器线圈、LED 灯带或大栅极电容的功率管。
- P11 的 11 针（5 V）、29 针（3.3 V）只给小功率器件供电（IMU、编码器、USB-TTL 的逻辑侧）。舵机、电机、雷达单独供电，只共地。
- 当前导航比特流里，P11 上没用到的引脚都是**带弱上拉的输入**（布线报告第 7 节 `in / UP`）。整车线束上的使能类信号必须靠外部下拉保证安全（第 6 节）。

### 4.1 超声波与SG90连接

| 外设信号 | FPGA方向 | 排针物理针号 | GPIO网络 | FPGA球脚 / Bank | IO约束 |
|---|---|---|---|---|---|
| SG90信号线 / `SCAN_SERVO_PWM` | 输出 | P11-36 | GPIO0_31 | B13 / 2 | LVCMOS33，8mA，无片内上下拉 |
| 超声波Echo / `HCSR04_ECHO` | 输入 | P11-37 | GPIO0_32 | A13 / 2 | LVCMOS33，片内弱下拉 |

采用上游Trig/Echo接口。若实际模块Echo为5V，须先转换至3.3V再进A13；FPGA IO_TYPE和弱下拉不能代替电平转换。SG90电源按实物规格单独供给，与FPGA共地，B13只接PWM信号，不从IO供电。该SG90是附加扫描舵机，与P11-1…4四个腿舵机分开编号。

`range_servo.v`以50MHz时钟和1µs使能运行：触发间隔65ms、Trig高12µs、等待/回波超时30ms；舵机周期20ms，三档脉宽500/1500/2500µs、默认每档50帧。脉宽对应的实际角度与可用机械行程须按安装核对。源码声明103位寄存器，结构没有RAM数组、乘法器或PLL；这是静态判断，实际LUT/FF及连线代价由联合报告确认。

## 5. BMI088 接口与共享方式（当前 I2C）

当前控制驱动 `fpga/src/bmi088.v` 使用 I2C：SDA=P11-7/F18、SCL=P11-8/E18；约 10 ms 轮询，加速度/陀螺两组成功后发布六轴样本。配置为加速度 ±3 g/100 Hz、陀螺 ±2000°/s/2 kHz；后者是芯片内部 ODR，不是并行输出 2 kHz。

`main.cst` 对 BMI088 的 SDA / SCL 设置 `PULL_MODE=NONE`，I2C 上拉由模块或外部电路提供。连接前核对模块供电、接口选择与地址脚，并确认上拉为 3.3 V；小板供电能力以该模块原理图为准。

控制融合 `imu_fusion` 已输出控制系 Q12 三轴角速度、投影重力和有效脉冲。首轮整车复用这一采集与融合链，内部扇出给导航；导航边界执行 `(x_nav,y_nav,z_nav)=(y_ctrl,-x_ctrl,z_ctrl)`，补采样时间、欧拉角换算和新鲜度检查。策略训练坐标保持不变。坐标推导及未实现项见 [ICD 第 1、5 节](icd.md)。

历史 v0.2 曾提出 SPI 接 P11-1..7、专用 1 kHz 采样；这些针脚当前已被舵机/OLED/IMU占用。该方案尚未实现且已撤销为当前接线依据。未来若实测证明 I2C 速率/时延不够，再独立评估 SPI、另分引脚并同步更新控制时序，不能据历史表改动车上接线。

## 6. 安全相关的电平设计

- 比特流下载过程中、FPGA 未完成配置时，用户 IO 的状态由器件决定（以高云手册为准，按最坏情况弱上拉考虑）；
  导航单独的比特流里，P11 上未使用的引脚是带弱上拉的输入。因此：
  - 驱动使能、电机电源、舵机电源一律**高有效 + 外部 4.7–10 kΩ 下拉**：FPGA 不主动拉高就保持断开；
  - 舵机 PWM 线串 100–330 Ω 电阻并对地下拉；PWM / DIR 型驱动板要确认"使能无效时忽略 PWM"；
  - 驱动板故障输出用开漏 + 上拉，断线读到"故障"。
- 物理急停与使能接线仍待现场确认；P11-8 已用于 BMI088 SCL，旧急停分配撤销。应先确定驱动板与独立功率切断回路，再分配另一组触点的 FPGA 输入，不能把 IR 5 键当物理急停接线已完成的证据。
- 旧文档“常闭接地 + 外部上拉、低有效急停”的文字自相矛盾：按该电路，正常闭合为低，按下/断线为高，应以高作为故障条件并同步到高有效 `ext_stop`。最终极性、去抖与故障电平必须按实际线束冻结，当前导航顶层 `ext_stop=0`，控制顶层没有物理急停端口。
- 导航 `SAFE.CTRL.ESTOP` 使目标直接为零；主机 `mode estop` 经固件提交零目标。二者是否继续平衡取决于待实现的适配。控制仓库 IR 5 键/故障硬停会关闭轮输出、保持舵机，不等价于继续平衡。详见 [ICD 第 4.1 节](icd.md)。
- S0 会复位当前控制链并使其重新标定；整车应划分导航软核复位和控制复位。导航单独工程已有软核复位命令，但整车隔离及故障动作尚未实测。

## 8. 改引脚的流程

1. 先改本文件（分配表与版本号），导航组与相关组确认；
2. 按所选工程更新约束，端口名与顶层一致：导航独立台架为`gowin/nav_board.cst`，联合候选使用其冻结输入生成的`g2.cst`，不能把独立台架约束覆盖整车；
3. 按对应构建入口综合/布线后，核对实际引脚报告：每个端口的球脚、Bank、方向、IO类型和CPU/SSPI等复用选项；
4. 上电前用万用表通断档核对线束，量 TP8 = 3.3 V；
5. 同步 [hardware_guide.md](../3_guide/hardware_guide.md) 的接线表。
