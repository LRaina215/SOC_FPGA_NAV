# G2结构简化与验证顺序

本方案以正确SFP1 Lane2、544条未布通/334块BSRAM的完整工程为物理比较基线。简化目标是降低实际逻辑、寄存器、DSP及连接压力；不以代码行数或功能多少解释全部布线失败。失败网络身份和拥塞位置仍未取得，尚不能确定唯一根因。偏置ROM版虽然逻辑减少，物理未布通反而增至2950条，已经说明单项资源减少不保证联合布线改善。

## 合同与范围

保留原4500策略及全部权重、125Hz周期、原单位/符号/舍入/饱和、使能与故障停止优先级、传感器接入、真实SFP1 Lane2、完整控制遥测及原协议。CPU RAM、地图/点云缓存、历史帧和权重容量保持。私有中间值可改用等价表示和复用运算，不丢弃对外信息。

当前先执行保留功能的结构简化。功能裁剪或将工作迁移RK3588属于另一项架构调整；若采用，需要明确实际保留的业务、实时性、通信与停止边界，不能把缺少模块的诊断结果当成完整工程通过。

## 后续结构简化顺序

1. **接续观测候选的驱动核对和物理比较。** 第一轮完整综合已确认资源收益； 使用相同完整源，仅派生上述一个RTL文件。重新核对104份固件/存储资产、所有BSRAM叶与参数、真实SFP与完整遥测、实际LUT/FF/DSP及最坏路径。综合频率估计只能用于筛选。若没有真实收益或新增关键路径，继续局部分析，不原样反复PNR。
2. **审计宽快照和内部交接。** 观测输出与策略端4032位快照之间存在可研究的存储/连接开销。先证明生产者何时保持数据、消费者何时读取、复位/故障/重试时谁拥有快照，再评估内部按词交接或分银行表示。保留168次策略装载的内容和外部时刻；不能直接删除保证帧一致性的快照，也不预先承诺减少4032个寄存器。
3. **审计遥测保存与缓存。** 当前SFP完整控制V2已经复用原UART字节流及CRC，不能把它误称为两套重复计算。进一步区分必要的跨域/双缓冲与可消除的私有复制，保持全部字段、序号、时间戳、CRC、丢弃/过期与不阻塞控制的合同。
4. **按真实面积和路径继续导航算术复用/精确位宽。** 保持点流吞吐、背压、帧语义、现有存储容量与核心/接收域频率。先模块对照、再相同完整输入的联合测量，不同时叠加多项难以归因的改动。

已准备的14目标观测全局分配CST方案保留为后续对照，本次暂缓启动它。先评估结构简化，避免将RTL变化与另一组分配变化混在同一比较中。新综合可能改变自动生成网名，必须重新证明驱动和CDC，不能直接套用旧网名约束。
