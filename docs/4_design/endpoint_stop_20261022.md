# 终点与停止：航向积分、实际反馈和命令有效期

2026-10-22。当前整车状态与顺序只维护在[总计划](../1_plan/system_integration_plan_20261021.md)。本页记录专项事实；未部署，原4500训练、权重和控制快照未修改。

## 1. 已确认的航向数值缺陷

`pose_odom()`原实现每个反馈包单独计算`wz*dt*65536/6283185000`，余数丢失。10ms反馈时，小于约9.59mrad/s的单拍增量可被全部截断；持续转动也会累积有方向的截断误差。XY已有亚毫米累计，航向没有。它是源码中可直接构造的缺陷，不能据此把所有历史假到达归因于它。

隔离候选保留有符号64位余数；绝对航向和绝对重置时清除余数。未改变零偏算法、评分、目标容差、控制策略或地形准入。入口[构建脚本](../../sim/closed_loop/build_endpoint_yaw_candidate.py)，可审阅的[补丁](evidence/endpoint_20261022/yaw_fraction.patch)。生产fw仍为AS，候选尚未合入。

[24组实际C积分反例](evidence/endpoint_20261022/yaw_numeric_contract.json)：±3/20/100/600mrad/s，1/10/20ms反馈，10s总时长；与按总时长独立计算的整数角度比较。修复前最大误差14.183°，修复后24组误差均为0个角度单位，另测绝对航向重置。这个结论仅针对数值积分。

## 3. 零偏与零请求漂移的边界

AS两侧35s只读C记录中`bias_n=0,wz_bias_q8=0`，最长连续静止候选20ms，未满足300ms估偏条件；2s“标定等待”没有建立导航零偏。两侧实际运动相同，说明等待时间不能当作已标定或已停住。仿真按既定种子注入的陀螺偏置仍在；修复后残余航向误差不能继续归为截断。

不能将这个仿真结论直接搬成“实机BMI未标定”。实际控制`mem_policy`先做BIAS_SAMPLES=200，`ready`还检查calibrating/bias_suspect/50ms样本年龄；G2反馈用其融合角速度且要求model_ready。native运行器并不等于完整BMI RTL执行链。G3必须将校准状态、反馈年龄和坐标约定带到导航，避免重复估偏或把运动当静止。离线无法确认实物剩余零偏、轮径/打滑、刹停减速度上界。

先前BH保持实验改善有限时间内的平移，但真实航向仍漂移约5.3°；本次BJ修复的2s漂移基本不变。因此不把发零、数值积分修复或未标定停止模型当作物理停稳。

## 4. 命令有效期原型与实际故障注入

[command_lease_guard.v](../../integration/g2/command_lease_guard.v)已经实现完整合法事件入口：原子速度对、200ms年龄、唯一owner/session、16位半范围序列比较（含回绕）、范围拒绝、1ms有界目标减速、反馈50ms失效、复位/切换/失联后重新握手。恢复需要新的零指令与500ms实际反馈停稳；测得6mm/s平移或30mrad/s转动不会恢复。通信停止不禁用平衡策略，物理急停单列。

[RTL证据](evidence/g2_20261022/command_lease_contract.json)为**24项**合同：实际原UART位接收与CRC解析器的断线、持续坏CRC、越界、半包；直接入口的重复/迟到/回绕、错源/旧session、反馈丢失、零请求仍漂移、切换、源故障、急停释放和复位恢复。仿真缩放时钟；原型参数与真实物理包络未标定。早期stdout与工具日志同名造成重复行，已分离日志并按TEST PASSED计数，不能报告33项。

G2可用`--command-lease`接入实际NAV SAFE→原4500通路，NAV为唯一owner；SAFE自身200ms原始命令看门狗作为上游故障输入，周期SAFE输出不能掩盖旧指令。下游单位转换采用与UART一致的对称最近舍入。资源/时序归[G2报告](g2_joint_resources_20261022.md)对应构建，不把旧无监管器结果当新版本。

**未完成的边界：** 当前线上旧UART协议没有传输序号/session，接收端本地计数不能识别重放的完整合法旧包；原型对直接带序号入口的合同不等于旧协议已具备该能力。G2内部NAV session固定，外部所有权切换/会话建立及遥测状态还需接口适配；本轮没有修改或烧录控制快照。没有实测刹停距离保证，也没有把该RTL与native闭环当作同一个受测控制器。

## 5. 接续依据

保留150mm标准，先把有效校准/反馈合同与不确定定位量接到同一停止候选，再测试可执行的终点修正和停止空间。受控减速的目标变化上界不是RL车体减速度下界；无物理证据时仍需STOP_UNCONFIRMED。坡道锚定、窄通道观察退出及BH2地图准入维持原失败结论，待共同资源明确后继续，不能借本次单例改善宣布N2/N3完成。
