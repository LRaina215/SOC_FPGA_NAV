## 1. 已完成的检查点

提交`cd9b816`保留此前未提交源码和既有团队文档内容，未将失败实验说成接受基线。N1c的54个构建/源码文件已从被忽略目录另存进Git；AS源码在fw，AY/BJ/BH2补丁及构建脚本在sim/closed_loop/candidates。见[检查点说明](../../reference/checkpoints/README.md)。原始点云、完整物理状态、视频和失败数据保留在`F:/nav_terrain4500_20261022/evidence`，仓库sim/build/terrain4500_20261022仍为联接。

## 2. 先完成G2：真实共同工程资源

交付源码入口、器件/时钟/约束、有效通路、模块与存储分解、综合报告、可布线时的实际占用和时序。入口[build_g2.py](../../integration/g2/build_g2.py)，测量见[G2报告](../4_design/g2_joint_resources_20261022.md)。

1. 同一共同工程比较AS基础导航（覆盖层关闭）与AY覆盖候选（开启），均运行128KiB导航软核及原4500网络/ROM。使用当前RTL只改变覆盖层开关，不拿不同历史顶层直接相加。暂以控制工程的器件C版统一构建，实板B/C仍未核实。
2. 实际控制通路、ROM、BMI088输入、编码器反馈、PWM、舵机和遥测输出保留，检查综合层次与存储实例，不能靠优化掉策略过闸。完整BMI重力到导航姿态/时间适配属于G3，接口桩须列明。
3. 先测原始联合综合。超过340硬上限或336工作门槛时，按双方分解做存储打包、分层无损位宽、常量特化或物理共享，保持算法容量、原4500权重数值与训练不变，不预设只压某一方。
4. 可进入PNR即继续测实际BSRAM/逻辑/DSP和50MHz核心时序。综合与PNR分开，异步域和未标定IO时序不能当作整车签核。无烧录授权。
5. 结论前不增加FPGA地形存储、不重复94例或扩大地形批量。不得以缩堆/栈或删除有效通路过闸。

本轮测量结论为**G2不通过**。已经按双方模块分解尝试多种无损布局，数值/有限RTL对照通过而物理资源不通过；不能反推“还差几块就能部署”。接续先隔离查清综合到PNR的存储映射开销，并对真正可共享的读端口/ROM或流水安排做局部原型后再联合测量；硬件功能扩展维持暂停。终点/命令专项可继续离线实现，但不跨过这个资源门槛部署。

接续已查明具体来源：PNR默认实际命令开启32/36位RAM拆为两个16/18位RAM，宽叶子数能解释339与实际需求的差额。现在显式关闭拆分，对原网表保持算法/数据/器件/约束不变重做PNR；已进入布局，336工作门槛与50MHz时序仍待验证。细节和机器可读归因见[G2报告](../4_design/g2_joint_resources_20261022.md)。

控制完整副本已提交`b1bf15f`，G2现从`control/fpga/src`加受检适配补丁生成，不再静默使用旧入口副本；后续控制/适配改动在同仓库提交。仿真默认路径也切换到control，原快照与副本16个策略帧的状态、速度和动作完全一致，仅作为路径迁移检查，不计新地形通过案例。

## 3. G2之后：终点精度与实际停止

从保存的假到达证据出发，冻结当前受测源码、运行器、原4500和评分，明确每组属于接受N1c还是AS/BJ实验。历史20例160–364mm只归对应历史版本，不是当前新统计。

依次分解：估计位置相对独立真值的误差、坐标/传感器/轮径标定、终点控制、命令→SAFE→RL→实际停止位移。保留150mm、速度/角速度停稳与2s独立观察，不仅改变声明或发零命令。修复前后同口径，保留未到达、假到达和漂移。不能离线确认的实物量等待实测。

模型中零车体目标仍可能使RL输出非零轮目标。隔离保持改善不等于地形准入与停稳已通过，见[地形报告](../4_design/local_map_terrain_feasibility_report_20261021.md)8.2。

本轮专项见[终点与停止证据](../4_design/endpoint_stop_20261022.md)。已冻结AS与BJ前后源码、保持150mm评分；仅修航向余数的BJ单例有改善，仍未处理全部终点误差。AS的35s记录显示导航bias_n始终0，不能把2s等待当标定成功；实际BMI原控制已自带静止标定，其适配状态需G3明确。

## 4. G2之后：统一命令年龄、所有权与受控超时

本次明确授权此项，优先于其他仍暂缓的控制改造；原4500权重、训练和推理合同保持不变。

- 统一入口，原子更新前进/转向，记录合法完整命令年龄。CRC错误、非法范围和持续坏帧不刷新有效期。10ms半包超时只处理解析器。
- 导航与调试源唯一所有权，定义切换、复位、序列/迟到命令与超时恢复，防止重新播放旧目标。
- 超时进入有界受控减速并回到平衡保持，区分任务停止、失联、控制故障和物理急停，不能简单断电。
- 验证断线、持续坏帧、部分帧、切换、复位和恢复；同时核对策略仍运行、斜坡/有效期、反馈与状态。RTL/离线通过不写成实车通过。

交付入口RTL/适配、接口说明、故障注入证据和资源影响。

已实现原型并做24项RTL合同，不等于外部旧UART协议已修好：它没有传输序号/session，本地计数无法鉴别合法旧包重放。G2内NAV为唯一owner，复位/失联后要求新零指令与实际反馈停稳，不自动恢复上次非零目标；外部会话、状态回读和物理停止包络仍待完成。

## 5. G3/G4与N2余项

上述任务完成后，再完善BMI/导航姿态、统一时间、轴向、反馈有效性、调试与自主任务接入，提交同一候选最终资源/时序。上车仍需授权并按支架→低速→任务验证。

N2余项见[导航专项](nav_optimization_plan.md)：坡道跨格区间来源/年龄与垂直一致性、按缺失证据选择可执行观察动作、为制动和保持留出可确认空间。固定±20/60°侧扫没有联合成功，资源明确后再按必要性接续，保留所有失败分支。
