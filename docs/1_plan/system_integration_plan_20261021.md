## 3. G2之后：终点精度与实际停止

从保存的假到达证据出发，冻结当前受测源码、运行器、原4500和评分，明确每组属于接受N1c还是AS/BJ实验。历史20例160–364mm只归对应历史版本，不是当前新统计。

依次分解：估计位置相对独立真值的误差、坐标/传感器/轮径标定、终点控制、命令→SAFE→RL→实际停止位移。保留150mm、速度/角速度停稳与2s独立观察，不仅改变声明或发零命令。修复前后同口径，保留未到达、假到达和漂移。不能离线确认的实物量等待实测。

模型中零车体目标仍可能使RL输出非零轮目标。隔离保持改善不等于地形准入与停稳已通过，见[地形报告](../4_design/local_map_terrain_feasibility_report_20261021.md)8.2。

## 4. G2之后：统一命令年龄、所有权与受控超时

本次明确授权此项，优先于其他仍暂缓的控制改造；原4500权重、训练和推理合同保持不变。

- 统一入口，原子更新前进/转向，记录合法完整命令年龄。CRC错误、非法范围和持续坏帧不刷新有效期。10ms半包超时只处理解析器。
- 导航与调试源唯一所有权，定义切换、复位、序列/迟到命令与超时恢复，防止重新播放旧目标。
- 超时进入有界受控减速并回到平衡保持，区分任务停止、失联、控制故障和物理急停，不能简单断电。
- 验证断线、持续坏帧、部分帧、切换、复位和恢复；同时核对策略仍运行、斜坡/有效期、反馈与状态。RTL/离线通过不写成实车通过。

交付入口RTL/适配、接口说明、故障注入证据和资源影响。

已实现原型并做24项RTL合同，不等于外部旧UART协议已修好：它没有传输序号/session，本地计数无法鉴别合法旧包重放。G2内NAV为唯一owner，复位/失联后要求新零指令与实际反馈停稳，不自动恢复上次非零目标；外部会话、状态回读和物理停止包络仍待完成。
