## 2. 先完成G2：真实共同工程资源

当前结论：**BSRAM占用和布线已过，G2整体仍不通过**。静态边界＋工具复制1候选于17:57完成，实际332/340块BSRAM（工作门槛≤336），Logic89584、寄存器39957、DSP163.5；核心要求50MHz，实际26.313MHz、5003个setup违例。接收域自身123.530MHz，达到100MHz约束且域内setup/hold均0；全局另外8条hold位于异步FIFO Gray指针到第一级同步器，最坏−0.211ns，不能直接按普通同域数据修复，也不能未经CDC审查添加例外。Recovery/Removal/最小脉宽最坏裕量均为正。没有烧录。

入口[build_g2.py](../../integration/g2/build_g2.py)，完整来源、失败分支和机器证据见[G2报告](../4_design/g2_joint_resources_20261022.md)。先前双流水同网表配对：拆分0实际314块/502条未布通，拆分1实际332块/411条未布通，均没有时序。新成功不能单独归功于复制选项，因为同时包含静态边界优化；工具确实生成了复制寄存器，但控制复位直接负载9153、快照CE4032仍高，不能宣称高扇出已解决。

确定的超限来源是PNR宽存储拆分：旧8次差额逐叶吻合；当前314个源BSRAM叶子＋18个新增物理块＝332。18个宽叶包括导航17和控制IK的36bit只读ROM1，18对均在实际物理网表匹配。逐存储属性保留地图/帧缓存/LUT/控制ROM容量与原值；不删模块、缩栈、量化、跳MAC或改125Hz策略周期。实际综合提示统一修为有效回读的50MHz，历史100MHz提示结果单列。

控制完整副本已提交`b1bf15f`，共同构建及闭环仿真读取`control/fpga/src`；来源与维护规则见[control/FORK.md](../../control/FORK.md)。后续控制/适配/验证一同在此仓库提交，原仓库快照保留。导入后的16帧状态、速度和动作完全一致，仅作为路径迁移验证。

已验证的无损候选包括轮速观测流水（四组符号、32帧逐拍相同）、精确命令单位流水（两轴各65536值穷举，正常接收多80ns、停止直接优先）和覆盖静态边界（251查询、16183点、1306次碰撞X毒化，外部与有效RAM端口逐拍相同）。这些验证不代替实际联合时序和实车验收。

下一步按实际长路径推进：

1. 原BMI模长`egz→sqrt_value`实际数据延迟37.915ns。候选只把平方结果寄存、在原sqrt引擎采样拍求和，保留原算法、标定参数、输出数值与周期；20万拍、两种时钟参数各288帧、64组24位极值/随机向量通过。首个carry-save写法触发Gowin SP00019内部错误，失败保留；改用显式扩展加法后RTL复验通过，正在与导航候选联合综合。
2. 导航`a_q→点流投影`实际37.028ns，其中位姿提交地址译码进入帧提交/反压链。候选在原总线捕获拍提前译码，不插入点流延迟、不改帧元数据；真实总线状态机内与未改的寄存器文件脉冲对照3091拍、83次提交、541事务、2种复位通过，完整联合综合待测。
3. 若综合可用，按同器件/引脚/SDC重新布线，回读设置并记录真实资源、50/100MHz及全局违例。不能用综合Fmax替代PNR；完整构建已增加报告门禁，即使厂商工具返回0，只要时序失败也返回失败并保存`g2_gate.json`。
4. 审查异步FIFO Gray指针/同步器与约束，保留8条跨域hold的独立来源；不为了通过而删除约束或一刀切忽略时钟域。器件实物B/C、完整IO/CDC与G3仍需独立验收。

## 3. G2之后：终点精度与实际停止

从保存的假到达证据出发，冻结当前受测源码、运行器、原4500和评分，明确每组属于接受N1c还是AS/BJ实验。历史20例160–364mm只归对应历史版本，不是当前新统计。

依次分解：估计位置相对独立真值的误差、坐标/传感器/轮径标定、终点控制、命令→SAFE→RL→实际停止位移。保留150mm、速度/角速度停稳与2s独立观察，不仅改变声明或发零命令。修复前后同口径，保留未到达、假到达和漂移。不能离线确认的实物量等待实测。

模型中零车体目标仍可能使RL输出非零轮目标。隔离保持改善不等于地形准入与停稳已通过，见[地形报告](../4_design/local_map_terrain_feasibility_report_20261021.md)8.2。

本轮专项见[终点与停止证据](../4_design/endpoint_stop_20261022.md)。已冻结AS与BJ前后源码、保持150mm评分；仅修航向余数的BJ单例有改善，仍未处理全部终点误差。AS的35s记录显示导航bias_n始终0，不能把2s等待当标定成功；实际BMI原控制已自带静止标定，其适配状态需G3明确。

## 4. G2之后：统一命令年龄、所有权与受控超时

本次明确授权此项，优先于其他仍暂缓的控制改造；原4500权重、训练和推理合同保持不变。

- 统一入口，原子更新前进/转向，记录合法完整命令年龄。CRC错误、非法范围和持续坏帧不刷新有效期。10ms半包超时只处理解析器。
- 导航与调试源唯一所有权，定义切换、复位、序列/迟到命令与超时恢复，防止重新播放旧目标。
- 超时进入有界受控减速并回到平衡保持，区分任务停止、失联、控制故障和物理急停，不能简单断电。
- 验证断线、持续坏帧、部分帧、切换、复位和恢复；同时核对策略仍运行、斜坡/有效期、反馈与状态。RTL/离线通过不写成实车通过。

交付入口RTL/适配、接口说明、故障注入证据和资源影响。

已实现原型并做24项RTL合同，不等于外部旧UART协议已修好：它没有传输序号/session，本地计数无法鉴别合法旧包重放。G2内NAV为唯一owner，复位/失联后要求新零指令与实际反馈停稳，不自动恢复上次非零目标；外部会话、状态回读和物理停止包络仍待完成。
