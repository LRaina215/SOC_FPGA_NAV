## 3. 三条独立证据链

### A：物理几何与传感器事实

从场景连续几何或独立高分辨率表面取得真实高度、坡度、边缘位置、沟槽宽深和接触关系。先比较高程数值与有效性，再讨论可通行性；禁止直接调用待测地图的危险判据生成“真值”。

虚拟雷达依据实际物理姿态、安装外参、XT-M60方向表、遮挡和采样时刻生成观测。未被观测的格保留未知，不将“未看到沟底”或“没有回波”填成安全平地。理想姿态/位姿只用于单列的诊断对照，不灌入普通导航闭环。

### B：固定原4500的条件性通过能力

先做直接速度/偏航命令的孤立地形试验，避免规划器拒绝进入地形使能力根本没有被测试。保留真实物理积分、动作限幅、接触和失稳，不能直接赋车体速度、强制姿态或抬升机器人。

分别记录进场速度、方向、腿姿/高度、摩擦、负载/质量假设、执行链版本和传感器条件。成功仅证明相应工况；单次失败不直接等价为所有控制器/所有速度都无法通过。对边界和不稳定结果做少量重复，先明确失败原因和适用条件。

坡度12°、台阶20mm继续作为旧假设和扫描起点，不再同时充当地图阈值与物理能力真值来相互证明。原4500能力、几何约束和感知正确性分别给结论。

### C：地图与导航的闭环决策

接入当前阶段结束时冻结的导航C、SAFE、固定策略、虚拟编码器/IMU/雷达，记录地图何时允许/拒绝、规划何时限速/绕行、车辆何时真正接触地形。

将“地图判断可通行”与B获得的能力范围关联；方向、速度和腿姿不同，结论也可能不同。若单一二维代价难以表达边界，先量化失配，再决定保守固定包络、轮迹查询或额外状态是否必要，不预设一定要重写地图。

## 4. 动力学场景必须正确

- **坡道：** 使用实际可碰撞斜面/楔体，含进坡、坡顶、出坡过渡；检查支撑接触和轮子实际高度，不用改变根节点Z或姿态模拟“上坡”。
- **台阶：** 实际抬高支撑面，分别测试上台阶、下台阶和斜向进入。当前后端把任何`scene_*`接触都记成失败，必须改为按对象和接触部位区分：合法轮地/轮坡/轮阶支撑不是碰撞失败，机身触地、卡死、倾覆等另记。
- **沟槽：** 底部、侧壁和入口/出口边缘真实存在，沟口支撑面确实缺失；无限大地板不能仍覆盖沟槽底上方，否则轮子会踩在隐藏地板上形成假通过。
- **机构：** 训练等效开链保留作原策略对照；工程验证应恢复或按有来源的几何构建真实五连杆闭合。几何、惯量、轮胎和执行器参数来源/未标定项逐项列明；缺失部分用明确范围试验，不能称已复现真车。
- **数字与执行链：** J3已验证的PID/编码器参考应逐步接入，舵机20ms锁存、轮速量化、动作保持、时延和驱动限制单列；训练等效执行器与部署近似执行器分别报告。
- 先验证场景碰撞表面和足端接触是否正确，再做能力统计；对沟槽尤其检查负空间未被高程场、碰撞凸包或隐藏平面填平。

## 5. 场景选择与顺序

先每类少量有代表性的工况跑通全链路，再围绕当前阈值、失败位置和可观测性边界加密；不做所有参数的笛卡尔积。

| 类别 | 首批内容 | 必须分开的条件 |
|---|---|---|
| 坡道 | 4°/8°/12°/16°/20°附近筛查，边界按结果加密 | 上坡/下坡、纵向/斜向/横坡、坡顶过渡 |
| 台阶 | 5/10/15/20/21/25/30/40/50mm代表高度 | 正负台阶、两轮同时/单轮先接触、正对/斜向、栅格相位 |
| 沟槽 | 由轮径与支撑几何选择窄/临界/明显危险宽度，至少两档深度 | 沟底可见/不可见、正交/斜穿、两轮同时/先后、近场盲区 |
| 维护与干扰 | 平地/地形边界在行驶中被反复观测 | 定位修正、地图滚动、旧危险消退、遮挡、丢帧与时延 |

每类先分“理想传感器与已知外参”和“当前噪声/延迟假设”；出问题再按单因素隔离。训练高度/质量、雷达外参及摩擦不是实测值时注明，不能把一组任意参数的成功推广为实车能力。

## 6. 判断局部地图是否做得好的分析项

| 层次 | 要测的内容 | 必须展示的失败 |
|---|---|---|
| 雷达与投影 | 覆盖率、有效点、遮挡/漏测、姿态/外参误差 | 盲区被误当平地、沟槽无回波被错误填充 |
| 高程维护 | 高度偏差分布、边缘偏移、坡面形状、样本量/有效性、数据年龄 | 平地长出假高障碍、正负地形混叠、过期证据长期残留 |
| 原始可通行性 | 已观测区的危险漏判与自由误报，按坡道/台阶/沟槽单列 | 地图高置信放行但物理失败；可通过地形被错误封死 |
| 未知与置信度 | 未知占比/持续时间、未知是否进入行驶支撑区 | 用大面积未知回避评分、将未知伪装成安全 |
| 膨胀与路径支撑 | 原始危险和膨胀代价分开；左右轮迹/车体净空 | 膨胀掩盖原始漏检、过度膨胀封死可用通道、轮迹踩空 |
| 时间/位姿一致性 | 采集、融合、匹配修正、地图写入、查询与命令时间 | 修正后旧图错位、危险格进入自身包络、发现危险已不足以停止 |
| 闭环影响 | 成功/失败、进展、停止距离、无效恢复、停顿 | 地图正确但控制失败，与地图误判导致失败混为一类 |

总体混淆计数必须同时给分母、样本范围和未知比例；原始危险召回与膨胀后阻塞召回分别统计。边界格单独给几何/栅格量化误差，不能把所有困难区域都划为忽略区。

必须保留四类对照：物理可通过/地图允许、物理失败/地图允许、物理可通过/地图阻塞、物理危险/地图提前阻塞；另列证据不足的未知。物理失败须解释是几何支撑不足、原4500稳定性/跟踪、执行器限制、建模差异，还是导航/地图决策，不能一律算成地图错误或一律替地图免责。

现有逐格地图若无法提供年龄/有效性等诊断，先在宿主机增加记录或离线旁路诊断，不在128KiB固件里盲目增加大数组。记录手段不应改变受测算法与时序而未声明。

## 7. 视频、数据与分析报告

每次试验从同一运行记录生成视频，不为拍成功视频换输入。保存：场景/模型/原4500与导航版本、参数、种子、命令、采样与地图帧时间、完整qpos/速度/接触、原始地图和判分结果。

视频推荐同屏显示：

- 三维运动与侧视地形，标出坡度/台阶高/沟槽宽深、运行编号和成功/失败状态。
- 雷达点云/遮挡与局部高程、原始可通行图、膨胀后代价图，清楚图例区分安全/危险/膨胀/未知。
- 车体/左右轮迹、计划与实际轨迹、姿态/速度、地图时刻与数据年龄；必要时显示独立几何对照中的误放行或误封格。

每类地形至少交付代表性成功和失败视频；若某类没有成功，明确全失败并给失败视频，不制造成功样例。其余所有试验均保存完整结果及对应视频/带索引合集。保留入场、首次判定/首次失效与失败后过程，不只剪最终翻车或通过瞬间。

报告结论按“在什么工况下可信／哪些区域过保守／哪些情况会漏判／需要改进什么／尚不能验证什么”组织，给代表地图帧、纵横剖面、条件性能力边界、失败归因和视频索引。视频中的可视化不能把未观测的真值偷偷填进导航地图。

## 8. 交接与完成条件

本阶段已于2026-10-22完成交接及本轮仿真/分析。AS/N1c与运行输入已冻结，后续从报告P0缺口接续；不重复发送本阶段交接，也不覆盖历史成绩。
