# 红外遥控前后左右

工程 `/home/cyd/fpga/fpga`。红外接收头使用参考工程 `main.cst` 的 **IRIN=A21，3.3V输入、上拉、空闲高电平**。

`src/ir_remote_control.v` 改编自 `/home/cyd/fpga/Documents/fpga_embedded_competition/src/ir_sensor.v` 的NEC下降沿间隔解码，沿用按键码、标准/扩展NEC地址兼容方式和180ms按键保持时间。省去原数码管扫描，增加复位和模型指令输出；未复制数码管引脚。

| 按键 | 命令码 | 模型运动指令 |
|---|---|---|
| 2 | 0x18 | 前进，+0.3m/s |
| 8 | 0x52 | 后退，-0.3m/s |
| 4 | 0x08 | 原地左转，+1rad/s，前进指令0 |
| 6 | 0x5A | 原地右转，-1rad/s，前进指令0 |
| + | 0x15 | 按住升高，松开保持高度 |
| − | 0x07 | 按住降低，松开保持高度 |
| 5 | 0x1C | 急停锁定：停止轮子、保持舵机姿态，硬件复位后恢复 |
| 其他有效按键 | 其他命令码 | 未急停时速度/转向指令均为0，停车平衡 |
| 松开/红外丢失 | 最后一次有效帧或重复码后约180ms | 未急停时速度/转向指令归零，继续平衡；高度保持 |

按住按键时，NEC重复码续期；重复码不能从无有效按键的状态启动运动，也不能复活已经超时的按键。命令与反码校验失败的帧不更新按键、不延长保持时间。遥控器没有独立松键帧，因此松开后最多约180ms才将运动指令归零或停止调高；后续模型和执行器仍有原来的更新周期。高度每10ms改变一个Q12单位，约24.4mm/s，限幅348～778 Q12（约85～190mm），初值由 `COMMAND_HEIGHT_M` 设置。5键收到有效完整帧后锁定急停，松开、重复码和其他键都不能解除；急停期间高度也保持。它覆盖常量速度模式与手动轮速模式。软件红外急停依赖红外接收，不能代替物理断电开关。

键码依据本机资料 `references/ACG750/器件手册/IR/红外遥控键码对应图.jpg`。

## 速度上限与平衡控制

- 前进/后退指令写死为Q12的±1229，约±0.3m/s；左右轮最终目标仍由原动作映射器限制到±600mm/s。
- 转向指令写死为±4096 Q12，即±1rad/s。
- 没有增速/减速按键；原PWM上限2400/2500（96%）保持不变。
- 运动路径：`IRIN -> remote_thread -> command_forward/yaw_q12 -> 模型观测与推理 -> 原双轮速度PID`。遥控不直接驱动PWM。
- 底盘初始高度 `COMMAND_HEIGHT_M=0.1305`，可通过+/−修改，舵机由原模型+高度IK控制。
- 松开按键后的0指令表示停车/平衡目标，不表示强制关闭电机PWM；模型可以给轮子纠偏速度。
- 原BMI标定、模型故障、电机故障及急停保护继续生效；红外按键不解除故障锁存。

## 顶层接口

`main.v` 的 `IR_ENABLE=1`、`FIXED_FORWARD_ENABLE=0` 默认启用遥控，已取消固定−0.05m/s；松开前后键后目标为0，仍进行平衡。`COMMAND_FORWARD_MPS=0` 是备用常量。设 `IR_ENABLE=0` 并重新编译可恢复常量指令和高度。遥控运动接入现有 `MODEL_ENABLE=1` 的平衡模式，`MODEL_ENABLE=0` 仍使用原来的手动双轮目标接口；5键急停在遥控启用时同样有效。

可在仿真/后续调试接口观察：`ir_key_code`、`ir_key_active`、`ir_key_event`、`ir_repeat_event`、`ir_forward_q12`、`ir_yaw_q12`。OLED保留六轴与模型诊断标题。

速度调整：遥控前进/后退固定目标为±0.3m/s。模型纠偏需要的左右轮最终目标上限仍为±0.6m/s；前进指令值不等于瞬时轮速硬限幅。初始高度约130.5mm，可调范围约85～190mm。
