# OLED 三文件结构

- `oled_front.v`：字符库，保留原厂 oledfont.h 的 ASCII 字模以及 16×16 汉字。
- `oled_driver.v`：功能资源，管理显存、初始化、绘图与刷新，包含 I²C 底层模块。
- `oled.v`：显示线程，锁存 LED_NUM，转十进制，逐位调用驱动，再刷新屏幕，循环运行。

调用关系：`main -> oled（线程） -> oled_driver（功能） -> oled_front（字库）`。

## 使用数字显示线程

`main` 实例化 `oled`，输入 `.LED_NUM(32位无符号整数)`。`DIGITS` 取 1..10，前导补零，位数不足显示低位；`FONT_SIZE` 取 8/12/16/24；`X/Y` 指定左上角。每帧锁存一次数值，不混合不同时间的数字。目前显示 1234565778，10 位，16 号字体，宽 80 像素。

## 线程可调用的驱动操作

在 `ready=1,busy=0` 时，保持参数稳定并给 `start` 一个时钟脉冲；等待 `done`，检查 `error` 再继续。绘图后发 op=5 刷新。

| op | 功能 | 输入 |
|---|---|---|
| 0 | 清本地显存 | 无 |
| 1 | 画点/清点 | x,y 像素坐标，mode=1/0 |
| 2 | 写字符/字母 | data=ASCII，font_size，mode=1 正常/0 反色 |
| 3 | 写 16×16 汉字 | data=字库索引 0..10，mode |
| 4 | 写显存字节/位图 | x=列，y/8=页，data=列字节 |
| 5 | 刷新全屏 | 无 |
| 6 | 原始显示命令 | data=命令，例如 A6/A7 反显切换 |
| 7 | 写单个十进制数字 | data=0..9，x,y，font_size，mode |

多位数字由线程转换并连续调用 op=7；字符串由线程逐字调用 op=2。ASCII 字宽：8 号为 6，其他字号为 font_size/2。任意 y 支持跨页绘图；屏幕边缘裁剪。非法数字或字号返回 error。

汉字索引依次为：中、景、园、电、子、技、术、有、限、公、司。原包 6×8 缺少 | } ~，显示空白。

## 接线与编译

50 MHz 时钟 W19；低有效复位 D21；OLED SCL F19/P11 pin5，SDA F20/P11 pin6，需要 3.3V 上拉与公共地。main 内含上电复位。初始化先尝试地址 0x3C，无地址应答时尝试 0x3D；两者均失败需修正接线后复位。全帧约 0.3 秒。

打开此目录下 fpga.gprj，重新加载更新后的工程文件，顶层使用 main。命令行：`bash build_oled.sh`。烧录文件：`impl/pnr/fpga.fs`。旧版源码位于工程根目录 backup_oled_three_files，勿加入工程。

## 用户添加字符的接口

修改 main.v 中 oled 实例化的参数即可，无需修改状态机：

```verilog
.TEXT("HELLO"), .TEXT_LEN(5),
.TEXT_X(0), .TEXT_Y(0), .TEXT_FONT_SIZE(16),
.DIGITS(10), .FONT_SIZE(16), .X(0), .Y(24)
```

TEXT 是 ASCII 字符串（字母、数字、空格和标点），TEXT_LEN 必须与字符数量一致；TEXT_LEN=0 不画字符串。默认最多 21 个字符，可用 TEXT_MAX 扩展存储，须确保 x + 字符数 × 字宽不超过 128。字号 8 字宽 6，12 字宽 6，16 字宽 8，24 字宽 12；y + 字高须不超过 64。当前线程显示一段静态文本和一段实时数字；它不解析换行和 UTF-8 中文。调整位置时文本与数字矩形不要重叠。TEXT_MODE=0 可反色。改参数后重新编译烧录。

如果你要编写更多显示步骤，在 oled.v 线程里调用 oled_driver 接口：写字符用 op=2、data="A"，写单个数字用 op=7、data=0..9；字符完成后等待 done，再写下一字符，最后用 op=5 刷新。已有的 TEXT_DRAW/TEXT_WAIT 状态就是这个握手的示例。

如果“加入字符”指的是添加新的字模（例如新的汉字），改 oled_front.v 对应 case 表即可；中文用驱动 op=3 和字库索引显示，不直接填入 TEXT。

## 再添加文字段

线程现在支持 TEXT、TEXT2、TEXT3、TEXT4 四段独立文本。后缀参数一致：TEXT2_LEN、TEXT2_X、TEXT2_Y、TEXT2_FONT_SIZE、TEXT2_MODE 等；LEN=0 跳过这一段。不是通过重复写 .TEXT 来添加；重复指定同一个参数会报错。

16号字体每行高16像素，可用 Y=0/16/32/48；数字区域也占一行，文本与数字需要不同位置。当前第一行 LED_NUM:，第二行 HELLO，第三行显示数值。可用 `.TEXT3("WORLD"), .TEXT3_LEN(5), .TEXT3_Y(48)` 加在最下方。ASCII 字符计数包括空格和标点；不支持在字符串里写换行来自动换行。
