# 停车微调（2026-10-15）

从新速度版 model_3000.pt 加载网络和优化器，追加1500轮，最终累计4500轮。原模型保留。网络、舵机IK与角度修正、左右轮独立速度动作、速度控制器及原奖励不变。

新增奖励只在前进及偏航指令均为零时启用：底盘中心平移速度平方×−60、偏航角速度平方×−2、距停车位置的水平距离平方×−12（平方距离封顶0.25m²）、距停车朝向的角度误差平方×−1.5。奖励按原框架乘控制周期dt，不强制把轮子速度置零。

中心点采用CAD base网格XY包围盒中心，坐标偏移[−0.080000002,−0.006656542,0]m。位置、方向只在进入停车或回合重置时记录；连续的零指令重新采样不刷新参考点，避免消除累计漂移。

原指令采样结束后，额外将45%的样本转成停车，预计停车比例约64%；其余运动和升降样本继续保留。原地升降也启用停车奖励。

位置和中心速度仅用于仿真奖励，不加入actor观测，不要求新增实物关节编码器。当前actor没有绝对位置观测，位置奖励有助于抑制漂移，但无法保证长时间绝对位置锁定。

流程：64环境停车逻辑预检与2轮PPO → 原模型64环境、平地、无探索噪声的20秒停车基线 → 4096环境保留原训练地形微调1500轮 → 同条件停车及前后、左右转、升降检查。指标仅统计首次失稳前的数据，并同时报告20秒生存比例，避免自动重置掩盖不稳定。

服务器结果目录：logs/parking_baseline、logs/parking_finetune、logs/parking_final。微调尚未完成时，本机窗口继续显示原3000轮模型。
