# 4500轮轮速模型 .mem

直接用于推理核ROM的文件：

- weights.mem：40704字，16位有符号，12位小数。
- bias.mem：425字，32位有符号，24位小数。
- elu.mem：3073字，24位有符号，12位小数。

encoder_*及actor_*的mem是对应分层权重/偏置，不需要与合并文件重复加载。输入/中间激活/输出使用24位有符号、12位小数；乘加累加器为48位。

网络接口：28维当前观测＋140维历史，先编码为3维潜变量，再拼接31维actor输入，输出六路动作。层顺序、偏移、格式和SHA256见manifest.json；误差和验证范围见error_report.md。

关节顺序：左髋、左膝、左轮、右髋、右膝、右轮。舵机沿用高度IK基础姿态＋action×0.03rad修正。左右轮独立输出目标线速度：物理左轮前进速度=−action2×0.6m/s，物理右轮前进速度=action5×0.6m/s。需要接入轮速反馈控制，不能继续按原扭矩模型的PWM缩放方式解释轮子输出。

本次只导出并验证模型文件；没有修改主工程、综合、生成fs或烧录。原model/mem目录保留。独立验证工程的推理核ROM路径已指向本模型的导出文件。
