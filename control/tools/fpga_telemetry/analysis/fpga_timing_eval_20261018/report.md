# FPGA时序与PID接入原4500仿真：评估报告

## 结论

同一4500在原仿真中全部工况稳定；加入实际采样/输出节奏和整数PID后，多项工况失稳。因此原策略对执行器动态差异明显敏感。由于PWM到力矩、电机空载速度和舵机机械动态尚未实测标定，本实验不能定量复刻真车，也不能把失稳唯一归因于延迟。

## 固定和移植的参数

- 权重未修改：`a0c0024e132b71d10fc42cc92081129e2738e8148b0191f56acf7eecfc73d99b`。模型仍为28维当前输入、5帧历史、6路动作。
- 物理步长2 ms；模型8 ms更新；1.67 ms计算延迟用一个2 ms物理步近似。
- 编码器1320计数/圈、65 mm轮径；10 ms计数窗；PID反馈四舍五入到cm/s；模型轮速观测使用原始计数换算。
- 轮速PID每10 ms更新，P/I/D/FF Q12分别为10240/1434/8192/3277；导数滤波α=1/4、D限幅250；积分抗饱和；PWM限幅2400/2500；目标斜坡每次100 mm/s；零目标清PID并滑行。
- 保留堵转100样本与反向10样本保护；本次未出现电机保护触发，记录到的失败来自仿真倾倒/碰撞判据。
- 舵机50 Hz锁存；完整接口组使用工程IK ROM及19 µs动作修正、500~2500 µs限幅，假设500~2500 µs对应π rad且机械零位等于CAD默认位。
- IMU按10 ms保持，使用真值经Q12量化；未仿真BMI088噪声、零偏、融合滤波及IIC传输。
- 前后/转向指令阶跃与原IR相同；高度按IR每10 ms变化一个Q12单位；高低目标差约100 mm。

## 方法

共420个环境，6组控制条件×7种工况×10种时序相位。无噪声、无外部推力，不修改质量/质心。3秒开始指令，13秒松开，18秒结束。失败沿用原配置的30°倾角及碰撞判据。每个环境第一次倾倒后不再计入有效速度均值，自动重置后的数据不算成功。

## 如何解释

- “原P控制＋实物时序”保留原仿真P参数，只更改采样/保持节奏，是诊断组，不代表实物PID；其失稳不能称为实物必然如此。
- 完整PID组不是直接套用仿真P值，而是使用已与RTL核对的整数PID。PWM映射为平均电压驱动的简化直流电机模型：τ=τ_stall×(duty/2500−v/v_no_load)，零目标和保护时滑行。
- τ_stall=0.15/0.30/0.50 N·m、v_no_load=1.0 m/s均为明确假设，扫描用于检查敏感性；不能当成520真实参数。
- 三种驱动力假设结果不同，说明驱动匹配和时序一起重要；没有证据证明单独提高FPGA主频可以解决。
- 不同工况和模式占据不同环境位置，且没有多随机种子统计；10个样本主要覆盖时序相位。
- 高度阶跃的初轮诊断另存step_height_diagnostic；正式结果采用真实IR高度变化速率。

## 下一步

先用实物轮速/PWM数据拟合电机代理的加减速响应，尤其双向制动和低速死区；必要时加入舵机动态与质心范围。确认仿真能复现主要波形后，再微调策略并考核80%车速指标。当前不应仅据本实验选择新PID参数。
