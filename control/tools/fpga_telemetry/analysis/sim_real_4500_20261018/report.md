# model_4500仿真与实物传感器对照

## 方法

- 使用原model_4500.pt，SHA256：`a0c0024e132b71d10fc42cc92081129e2738e8148b0191f56acf7eecfc73d99b`。
- 仿真使用保存的parking_config.json与vendored环境；96个环境分三组，每组32个。平地、无观测噪声、无推力，输出倍率1。
- 0~3秒零指令，3~13秒分别为0、+0.3、-0.3 m/s，13~15秒归零。96/96环境完成本次15秒运行，未发生失败。
- 实物使用fpga_20261017_213102.csv前2740行（21:32:46~21:33:41原1倍模型记录），排除固定速度和后来的倍率版本。
- 仅选择左右轮目标分别落在+0.30±0.03或-0.30±0.03 m/s的有效模型帧；比较的不是车身指令恰为0.3。
- 倾角均由投影重力按相同公式计算；机体X轴角速度对应此车的前后转动。

## 车身速度指令±0.3时的仿真稳态

从施加指令2秒后至松开前统计：前进实际车身速度0.252 m/s（84.0%），后退-0.176 m/s（58.7%）。因此原4500在本次仿真中后退也没有达到80%目标。

## 结论和限制

相近轮速目标下，仿真和实物的轮速、姿态及角速度分布不相同，不能把同一个瞬时输出当成相同控制状态。仿真中轮速反馈通常紧跟目标；实物在这些短暂修正帧中有显著误差。实物其他固定0.3测试能达到0.29，故不能据此说电机恒定0.3永远不可达。

两边不是同状态同历史的A/B：实物指令多为零或后退，仿真筛选来自三组不同阶段，输出筛选本身偏向瞬态；实物对应帧很少，仿真帧还存在时间相关和同初态重复。禁止将上述误差比值直接解释为控制器精度倍数或确定因果。

仿真记录的是无噪声真值角速度和投影重力；实物为BMI088经校准和融合后的估计。姿态均值不同可能来自实际姿态、安装、重心或估计，不能单凭均值认定IMU错误。仿真没有重现电流、电压、死区或实际舵机反馈。
