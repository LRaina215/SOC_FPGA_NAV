# 7000模型2ms轮速环候选版

- 模型：原始7000，18位F12权重，轮速1倍；推理周期8ms。
- PID：500Hz；反馈32位整数mm/s，P2.5、I0.07/样本、D10/样本速度增量、FF0.8。以原保守10ms参数换算，不沿用7000旧测试时的大P/FF。
- D滤波改为移位alpha=1/16，时间常数约31ms（前一精确换算约34.8ms）。斜坡20mm/s/2ms，保持原来100mm/s/10ms；零目标仍关PWM。
- 堵转500样本=1s，反向50样本=100ms，反馈超时仍200ms。
- 混合测速：每2ms发布。窗口至少4个净脉冲用计数法；低速用同向相邻脉冲周期，缺脉冲时用脉冲年龄衰减，50ms无脉冲归零（发布还有最多2ms相位延迟）。起步/换向需2个同向边沿才建立周期估计。
- 编码器1320CPR、轮径65mm、左正右反不变。模型继续接收原来的10ms原始计数，串口原始delta/cm/s也仍是10ms；PID内部实际反馈可由reference-error还原。串口PID控制序号在10ms帧间通常增加5。
- 舵机20ms、IMU约10ms、UART230400和100Hz帧不变。

新写法：默认24位周期除法、两拍减法/商移位，定点计数换算；每2ms固定发布，避免计算路径长度改变发布周期。60组正负周期/计数、饱和与cm/s换算对照精确公式误差不超过1mm/s。

新测试：tb_hybrid.v验证500Hz发布、低速稀疏脉冲、停转、换向和计数模式；tb_pid_2ms.v验证mm/s精度、30ms到0.3m/s斜坡、保护次数。原10ms测速、PID、PWM、UART及红外回归保留。tb_main_rom7000检查18位权重及越16位范围数值。

注意：2ms是计算/发布周期，不保证2ms获得全新低速物理信息，不能修复编码器接触/电气噪声，也不等于机械响应加快。未烧录及实车验证。构建产物仍为fpga/impl/pnr/fpga.fs，旧4500和7000均有备份。
