# SF课程源码对当前FPGA轮腿项目的参考价值

本次只读审查第3至9课的应用源码、IMU/PID/舵机库、BLDC接口与工程配置；没有编译运行课程，也没有审阅PDF正文。未修改FPGA控制源码、模型、正在运行的训练或烧录。

课程是ESP32-S3/Arduino/PlatformIO应用，使用MPU6050、PCA9685舵机驱动和SF_BLDC串口电机板；不是RL训练工程。可借鉴机制，不可直接复制PID数值或当作520驱动的已验证实现。

init先校准陀螺零偏，再update读取加速度角，然后明确写angle[0]=angleAcc[0]、angle[1]=angleAcc[1]。这与把上电姿态直接设为水平不同。当前FPGA imu_fusion.v复位重力为[0,0,-4096]，bias_done没有用加速度重力初始化，先前独立RTL测试已经复现启动姿态收敛慢。最值得借鉴的是启动时用稳定窗口的加速度平均方向归一化初始化重力；BMI088寄存器、坐标变换和浮点互补公式不能直接照抄。动态加速度影响和静止判定仍需处理。此项此次未实施。

## PID参考：积分独立预算、按时间计算

[第九课_仿生腿实现高机动性/lesson9_enhance/lib/pid/pid.cpp](</home/cyd/下载/SF-轮足机器人资料0720/SF-轮足机器人资料0624/SF-轮足机器人资料0624/4课程代码/第九课_仿生腿实现高机动性/lesson9_enhance/lib/pid/pid.cpp:23>)

PID按micros得到Ts，积分用梯形I*Ts*(e+e_prev)/2，积分单独限为±limit/3，最终输出限为±limit，再限制输出变化率。当前FPGA已有积分限幅、饱和条件冻结、D项限幅和参考斜坡，不能说缺少这些保护。区别在于FPGA积分允许占到全部PWM限额，课程库把积分预算限制到三分之一；课程限制的是控制器输出变化率，FPGA当前限制的是速度参考变化率。是否降低积分预算要通过回放/实验，不能依据示例直接改为三分之一，也不能认为再加输出斜坡一定改善平衡。

课程main实例PID_VEL{0.2,0,0,1000,50}实际I/D为0，而且它把速度误差映射为目标倾角，后面再用倾角误差计算电机命令。当前P=3速度环是mm/s误差到PWM ticks，两者单位、层级、时间参数均不同，数值不可比较。

## 值得研究：腿轮协同

[第九课_仿生腿实现高机动性/lesson9_enhance/src/main.cpp](</home/cyd/下载/SF-轮足机器人资料0720/SF-轮足机器人资料0624/SF-轮足机器人资料0624/4课程代码/第九课_仿生腿实现高机动性/lesson9_enhance/src/main.cpp:90>)

第九课X=-Kp_x*(targetSpeed-speedAvg)把速度误差转换为腿端前后偏移，再送IK；不是只要求轮子加速、让腿保持原位。这能作为观察RL是否学到合适腿轮配合的对照，也可作为后续仿真中的基线或先验。用户当前要求核心平衡由RL完成，不能把该补偿直接叠加到部署端而不在训练中体现；它可能与模型腿部动作互相干扰。Kp_x=1.1和速度单位不能直接移植。

## 升降/左右腿分配

第六课Y=Y+0.1*(Y_demand-Y)平滑高度，第七课用E_H=(L/2)*sin(Phi)分配左右腿高度；第八课再积累横滚误差修正左右高度。这些可用来核对IK几何和为将来的功能做基线，不是复杂地形识别或地形生成器。

课程腿长L1/L4=60、L2/L3=100、基座间距L5=40（代码未显式标注单位，数值通常按毫米解释）。当前原4500配置l1=.075m、l2=.125m；必须使用自己的几何。课程设0~300度对应500~2500µs，你的舵机定义是180度范围，映射不能直接替换。

## 源码本身的限制和遗漏

- 第四课main.cpp第72行每轮把targetSpeed写成0，会覆盖前面串口读取；是零速示范，不能直接测试前后走。
- 第五课main.cpp第92行把targetSpeed写死15；turnKp声明后未找到赋值。第八、九课也未见turnKp赋值，全局默认0，转向项在这些源码中为0。
- 第八、九课stab_roll每循环累加误差，没有显式Ts或限幅；loop也未固定调度，因此不能把Kp_roll直接当作固定周期PID参数。第六课高度平滑同样依赖loop频率。
- IK sqrt判别式/除数未见统一的不可达目标保护；任意叠加X与高度可能产生NaN，不能直接拿来扩大动作范围。
- 第三/四/五课提供SF_BLDC头文件和预编译libSF_BLDC.a，本目录没有SF_BLDC.cpp；第八/九课目录未找到该静态库而platformio.ini仍要求链接它。缺失时需另行提供库才能编译。
- 应用变量命名为torque，但mode4的语义、目标单位以及驱动板内部控制环没有在这些头文件中定义，不能据此声称它输出真实Nm，也无法从该目录恢复电机测速滤波/内部电流环算法。
- 课程没有520电机PWM-轮速的实测响应数据，不能用它替代我们自己的串口辨识。

## 当前决策

保留用户已选10ms/P3参数和本轮4500轮训练不变。若后续需要落地借鉴，优先单独实现并验证IMU启动重力初始化；积分预算、腿轮协同属于后续对照，不在本次审查中插入当前训练或硬件控制。
