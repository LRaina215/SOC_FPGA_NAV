## 2026-10-15 05:11:44 北京时间 assistant

**确实有“零目标就关闭 PID”的逻辑，但没有把模型轮速固定为零。**

模型模式下，PID 接收的是 `model_left_mmps / model_right_mmps`；顶部手动参数 `TARGET_LEFT/RIGHT_MPS=0` 会被忽略。

不过 [motor520_closed_loop.v:98](/home/cyd/fpga/fpga/src/motor520_closed_loop.v:98) 写了：

```verilog
if (!reset_n || !enable || target_mmps == 0)
```

目标为零时，它会清空 PID、关闭 PWM。**这意味着零速度时不主动抵抗轮子转动，与仿真的零轮速反馈不一致，应改为零目标时仍计算速度误差。**

但它不能单独解释“舵机也完全没反应”。如果模型输出非零，PID 本应运行；还要看 OLED 的推理计数和模型状态。
