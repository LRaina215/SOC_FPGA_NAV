# 160×120 RGB565联合候选

来源：`Chenyudog/fpga@715378aa3228d0cdcc382882ab53edc7400ef89c`。
联合底座：已审SYN50/PNR63，保持SLF128、CPU128KiB、原4500/全部权重/125Hz、V2遥测及原停止保护。

`rtl/`保留上游相机采集、测距扫描及PLL，模块名称增加命名空间。
新增两份19200×16双时钟帧RAM及640×480居中放大读出；未初始化像素由就绪门隐藏。
HUD保留上游数值转换、字模和渲染，改以144位数值快照传递，替代三份字符页。
`reference/`保存未改上游OLED、PID和HUD源；准备器选择性接入OLED距离头和PID启用修复。
生产遥测仍为V2，CH命令/P11-40遥测所有权保持；未启用上游V4诊断。

用仓库的`prepare_video160_joint.py`生成独立候选；`probe_video160_units.py`运行有限双缓冲、HUD对照和PID检查。
`run_video160_joint_syn.py`要求通过记录及相同受测输入，先核内存和实际实现选项，再运行一次40分钟联合综合。
所有这些入口都不烧板，不自动启动PNR。

首次有限验证：4帧共76800像素、76805检查；HUD 8组输入47040像素比较；PID 82次数值提交和启用、反馈超时、重武装通过。
这不涵盖完整相机初始化/畸形源帧、整LCD链、全G2数值、实际四时钟STA/CDC或实车行为。
新图像预计38块BSRAM，整机318只是预算，须读真实映射和物理报告。

板上镜像保持原样。综合后审全部旧RAM/INIT、CPU映像、新帧RAM实际深宽、PLL/四钟、同步器/载荷及外部IO；通过后才送无截止PNR。
