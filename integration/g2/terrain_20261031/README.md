# 10-31 第一步：地形去噪 + 右轮编码器滤波 + 固件定稿（PNR67）

起因（10-31 静态建图，见 `../k_bench_20261027/bench_fw/README.md`）：高程图每帧覆盖，格内 zmax/zmin 只来自一帧，
掠射地面的单点测距噪声（σ_z 约 10 mm）让地面格台阶、粗糙度频繁超限，零散致命格再膨胀 20 cm 把整片地面封死。
用户 10-31 明确：车不跨台阶，只要求能过斜坡和崎岖地面。所以台阶阈值不用为"能跨过去"放宽，
要做的是把噪声降下来，让斜坡、起伏地面判可走，3 cm 以上的突起照样判障碍。

## 改动

### 1. 高程图跨帧平均（`nav/rtl/map/elev_map.v`、`trav_v3.v`、`map_subsys.v`，模型 `nav/model/nav_fixed.py`、`nav_fast.py`）

新增 `MAP.CTRL.AVG`（位 4）与 `AVG_SHIFT`（位 7:5），复位值 `0x7D`（AVG=1、AVG_SHIFT=3）。槽仍是 53 位，字段重新解释：

- 低 16 位：Q3（1/8 mm）高度均值 A，点高度先限幅 ±4095 mm；高 16 位：Q3 平均绝对偏差 D（无符号）；cnt：累计点数（饱和 15）。
- 槽空、标签不符、已标记过期时重置为 A = 该点、D = 0、cnt = 1；否则 `A += (z − A) >>> s`，`D += (|z − A| − D) >>> s`。
  s 按已有点数 1 / 2–3 / 4–7 / 8–14 取 1 / 2 / 3 / 4（前几点近似算术平均），计满 15 点后取 AVG_SHIFT，且不超过 AVG_SHIFT。
- 可通行性分析里，高度 = A >>> 3，粗糙度 = D >> 3（mm）；其余判据（台阶、4 格基线坡度、落差、填补、膨胀）不变。
- AVG=0 时与原来逐位相同（逐帧极值），可在板上写 `MAP.CTRL=0x0D` 切回对比；切换后须写 `MAP.CMD.CLEAR`。

同时改了默认阈值：`VALID_CFG` 每格最少点数 1 → 4（平均模式下是累计点数，去掉只被打到一两次的飞点），
`THR0` 粗糙度 50 → 40（平均模式下是平均绝对偏差），台阶仍 20 mm、坡度仍 57 mm/20 cm（16°）。

依据（10-31 现场测量）：
- 9-30 的 M60 原始深度记录（30 帧静止）：逐像素测距噪声 9–15 mm，相邻帧偏差相关系数 0.004，单像素滞后一帧自相关 −0.03，
  8 帧平均后 2.7 mm，说明噪声基本是逐帧独立的，平均有效。
- 10-31 导出的高程图：地面格单帧内 zmax − zmin 中位数 24 mm、p90 66 mm；逐帧极值下即使台阶放到 40、粗糙度 90、每格 ≥3 点也只是把远处地面变成未知。

### 2. 编码器 A/B 滤波与合理性保持（`control/motor520_speed.v`、`control4500_core.v`）

10-31 落地时右轮读数在负载下跳到 14 m/s，导致摔车。PWM 开关噪声同时打到两根编码器线上、两相阈值不同，一个干扰脉冲就会凑成整个正交周期。
- `FILTER_CYCLES=150`：A、B 电平必须稳定 3 µs 才被接受（满速时同一相两个边沿约隔 270 µs）。
- `MAX_DELTA=120`：10 ms 闸门计数超过 120（约 1.9 m/s，高于电机空载转速）判为干扰，保持上一个样本，`sample_valid` 照常输出；`rejected_samples` 计数。
- 两个参数默认 0 时与原模块一致；只在 `control4500_core.v` 的两个实例上打开。

### 3. 导航固件（`K_fw_terrain1`，补丁 `fw_terrain1.patch`，相对 PNR66 固件源码）

- `hal_imu_config`：开机把 IMU 接收字节 FIFO 与时间戳 FIFO 重新对齐（台架上查到的"姿态永远过期、雷达帧全丢"问题）。
- 安装参数缺省改为下俯 2.1°、横滚 −3°（雷达相对 IMU）、离地 150 mm；仍可用 `APP_MOUNT_*` 宏覆盖。
- `hal_map_support`：平均模式下按 [A − e, A + e] 给出格内区间，e = max(0, D − 12 mm)，12 mm 是平地上测距噪声带来的平均绝对偏差上限；
  平地格区间退化为一个点，轮下支撑检查（`support_guard.c`，20 mm 能力）不再因噪声拒动。`hal_map_height` 不变（取区间中点）。
- 不含台架宏 `APP_BENCH_STATIONARY`。镜像 54332 字节，sha256 见 `hashes.txt`。
- 仓库里 `nav/fw/drv/hal_fpga.c` 同步了同样的换算（仓库固件在 HEAD 时栈门限检查就不通过，与这次改动无关，未处理）。
