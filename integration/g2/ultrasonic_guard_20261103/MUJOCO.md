# 超声波遥控避障：MuJoCo 运动结果

本任务按用户明确要求，以 `D:/Anaconda/envs/mujoco/python.exe` 的物理运动仿真为依据。**遥控前进档始终是原来的 +0.3 m/s，对应原 RTL 的1229 Q12，没有改成0.15或0.1。** 先前2034项是RTL断言累计次数，不能替代机器人减速、停车与站立效果验证。本轮不再追加RTL测试。

最新项目记录已核对：实板联调基线为PNR85、follow1固件，独立遥控方向键仍直接给原4500控制；本功能只处理遥控驾驶，不加载、改动导航避障算法。

## 本次实际运行

只使用同一个3×5 m平地、同一前方障碍、同一原4500策略，运行两段各20秒的必要对照：

1. **目标归零版**：600 mm内开始减速，250 mm停车锁存，之后仅向4500给零运动目标。
2. **停车保持候选**：前进阶段完全相同，仅停车锁存后增加100 Hz编码器反馈保持，抵消零目标下的前移。

SG90全程固定朝前，无扫描。模式默认关闭，1秒时模拟按0开启；2秒后前进键一直按住，原始请求保持1229 Q12，包括接近障碍与停车期间。物理步长2 ms，原4500策略8 ms，超声波测量65 ms，保护行为模型1 ms。未改变模型权重、质量、惯量或原生执行器增益，也未对仿真机身指定运动轨迹。

| 指标 | 仅目标归零 | 停车保持候选 |
| --- | ---: | ---: |
| 车体最小障碍间隙 | 174.7 mm | 203.7 mm |
| 最后2秒前移 | 12.3 mm | 2.7 mm |
| 最后2秒最大绝对前向速度 | 6.34 mm/s | 2.20 mm/s |
| 碰撞 / 倒地 | 无 / 无 | 无 / 无 |
| 场景全程最大倾角 | 7.77° | 7.77° |

这说明：**仅把运动目标改成零，不等于原4500会完全停稳。** 本例中停车保持显著减少了残余前移，但没有证明所有场景或实车通过。原始结果中“低于30 mm/s连续500 ms”的标志过宽，本报告不据此接受停稳；`summary.json`重新按3 mm/s连续500 ms列出观察结果，并保留末段漂移。

候选停车保持使用编码器10 ms计数、整数cm/s粒度产生的反馈，不偷用机身真值作控制。仅停车态采用比例0.5和积分0.5/s，修正限制在±0.05 m/s内；正常遥控前进档不使用该修正。它通过小幅目标修正让原策略继续平衡，未关闭车轮PWM。**此保持环目前仅在MuJoCo实现，尚未接入本目录的RTL或实板。**

## 还不能忽略的问题

当前九射线、15°锥角近似在起步俯仰时会命中地面，约2.319秒曾提前减速；真正接近前方障碍后才进入正常距离减速。这是当前理想化超声波模型下的结果，不能直接当作真实HC-SR04已经误报。安装高度、俯仰角和地面反射行为没有实测依据，未通过屏蔽地面命中来美化结果。

仿真假设探头在轮轴参考点前145 mm、名义机身高度上30 mm，车体包络沿用项目27×33 cm。实际安装应复核后再判断600/250 mm是否合适。场地小本身不能证明制动距离短；本例只支持把600 mm作为待标定候选，不支持随意继续缩短停车余量。

控制模型是原4500浮点策略及原生关节执行器，不是FPGA定点策略、真实轮速PID、电池、轮胎和实装载荷的完整复现。初次场景装载把机器人生成在后墙上，启动8 ms内发生碰撞；该无效场景保留在F盘。修正只是在初始化前把机器人放到场内，没有更改动力学来规避失败。
